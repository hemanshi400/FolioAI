Add your portfolio background images here.

- Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`.
- Recommended size: 1600x900 or wider for good coverage.
- Name images like `bg1.jpg`, `bg2.jpg`, `bg3.jpg`, ...

The portfolio page will randomly pick one of these images on load and apply a light white overlay so the content stays readable.

To add images:
1. Copy image files into this folder.
2. Commit them to the repo. Example filenames: `bg1.jpg`, `bg2.jpg`.

If no images are present the page falls back to a subtle gradient background.
